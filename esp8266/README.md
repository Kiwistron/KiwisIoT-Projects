# ESP8266 KiwisIoT Projects

IoT and AIoT projects using ESP8266 and KiwisIoT.

This directory contains hands-on projects for learning sensors, actuators, MQTT, IoT dashboards, and KiwisIoT.

## Platform

- **Microcontroller:** ESP8266
- **IoT Platform:** KiwisIoT
- **Communication:** Wi-Fi, MQTT
- **Project Level:** Beginner to Advanced

## Projects

Each project includes the required source code, circuit diagram, wiring information, images, and documentation.

Projects cover sensors, actuators, automation, monitoring, and IoT applications using ESP8266 and KiwisIoT.
