## Getting Started

To start building these ESP8266 IoT projects:

1. Install the Arduino IDE.
2. Configure the ESP8266 board package and select your NodeMCU board.
3. Follow the [KiwisIoT Arduino Setup Guide](./kiwisiot-arduino-setup/).
4. Connect the sensor according to the wiring instructions in the selected project.
5. Configure your Wi-Fi credentials and KiwisIoT dashboard settings in the example code.
6. Upload the sketch, open the Serial Monitor, and check the sensor readings on your dashboard.

Review each project's README for its specific components, pin connections, library requirements, configuration, and testing procedure.

## What You Will Learn

By exploring these ESP8266 projects, you can learn how to:

- Interface sensors and electronic modules with an ESP8266 NodeMCU.
- Write and upload Arduino sketches.
- Read analog and digital sensor outputs.
- Work with sensor libraries and communication interfaces such as I²C and OneWire where required.
- Send sensor readings and device status to an IoT dashboard.
- Visualize measurements and status information using suitable dashboard widgets.
- Test, troubleshoot, and extend embedded systems projects.

## Who Can Use These Projects?

These projects are suitable for:

- Engineering students working on IoT and embedded systems experiments.
- Beginners learning ESP8266 and Arduino programming.
- Educators preparing sensor-based demonstrations.
- Electronics hobbyists building connected devices.
- Developers exploring sensor monitoring and IoT dashboard integration.

Component requirements, circuit connections, code, and difficulty can vary by project. Follow the individual project documentation before assembling the circuit.
