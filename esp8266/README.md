# ESP8266 KiwisIoT Projects

Hands-on **ESP8266 IoT projects using KiwisIoT** for sensor monitoring, automation, dashboards, and connected device applications.

These projects use the **ESP8266 NodeMCU**, sensors, actuators, Wi-Fi, MQTT, and KiwisIoT dashboards to build practical IoT and AIoT applications.

## Projects

### Sensor & Monitoring Projects

1. [ESP8266 LDR Sensor IoT Project with KiwisIoT](./001-ldr-kiwisiot/)
   - Monitor light intensity using an LDR sensor and ESP8266.

2. [ESP8266 IR Sensor IoT Project with KiwisIoT](./002-ir-kiwisiot/)
   - Detect object or vehicle presence using an IR sensor and ESP8266.

3. [ESP8266 Ultrasonic Sensor IoT Project with KiwisIoT](./003-ultrasonic-kiwisiot/)
   - Measure distance using an ultrasonic sensor and ESP8266.

4. [ESP8266 DHT11 Temperature & Humidity IoT Project](./004-dht11-kiwisiot/)
   - Monitor temperature and humidity using DHT11 and ESP8266.

5. [ESP8266 PIR Motion Sensor IoT Project](./005-pir-kiwisiot/)
   - Detect motion using a PIR sensor and ESP8266.

6. [ESP8266 Gas Sensor IoT Monitoring Project](./006-gas-kiwisiot/)
   - Monitor gas levels using an analog gas sensor and ESP8266.

7. [ESP8266 Flame Sensor IoT Monitoring Project](./007-flame-kiwisiot/)
   - Detect flame conditions using a flame sensor and ESP8266.

8. [ESP8266 Soil Moisture IoT Monitoring Project](./008-soil-moisture-kiwisiot/)
   - Monitor soil moisture levels using an ESP8266 and soil moisture sensor.

## Platform & Technologies

- **IoT Platform:** KiwisIoT
- **Microcontroller:** ESP8266 NodeMCU
- **Communication:** Wi-Fi, MQTT
- **Development:** Arduino IDE
- **Applications:** Sensor monitoring, automation, IoT dashboards
- **Project Level:** Beginner to Advanced

## About These Projects

Each project includes source code, circuit connections, wiring information, images, and project documentation.

The projects are designed for **students, engineering learners, educators, makers, and developers** exploring ESP8266 and IoT applications with KiwisIoT.
