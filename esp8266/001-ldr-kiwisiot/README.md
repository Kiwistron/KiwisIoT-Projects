# LDR Sensor with ESP8266 and KiwisIoT

A beginner-friendly IoT project using an LDR light sensor, ESP8266, and KiwisIoT for real-time light intensity monitoring.

## Hardware

- ESP8266 NodeMCU
- LDR sensor module
- Jumper wires
- USB cable

## Platform

- ESP8266
- KiwisIoT
- Wi-Fi
- MQTT

## Working Principle

The LDR sensor detects changes in light intensity. The ESP8266 reads the sensor value and sends the data to KiwisIoT through Wi-Fi and MQTT for real-time monitoring on an IoT dashboard.
