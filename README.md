# KiwisIoT Projects

A collection of practical **IoT and AIoT projects using KiwisIoT, ESP8266, ESP32, Arduino, sensors, modules, Wi-Fi, MQTT, and IoT dashboards**.

This repository provides hands-on projects for learning and building connected device applications, sensor monitoring, automation, and real-time IoT solutions.

## Technologies

- **IoT Platform:** KiwisIoT
- **Microcontrollers:** ESP8266, ESP32, Arduino
- **Communication:** Wi-Fi, MQTT
- **Development:** Arduino IDE
- **Applications:** Sensor monitoring, automation, dashboards, and connected devices

## Who Can Use These Projects?

These projects are useful for:

- Students learning IoT and embedded systems
- Engineering students working on IoT projects
- Educators and instructors
- Makers and electronics enthusiasts
- Developers building sensor-based applications

## About KiwisIoT

KiwisIoT is an IoT platform for connecting devices, sending sensor data, and visualizing information through cloud-based dashboards.

These projects demonstrate practical ways to connect microcontrollers and sensors with KiwisIoT for IoT monitoring and automation.
