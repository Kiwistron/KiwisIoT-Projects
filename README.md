# KiwisIoT Projects – IoT, AIoT, ESP8266, ESP32 and Arduino

A collection of practical **IoT and AIoT projects using KiwisIoT, ESP8266, ESP32, Arduino, sensors, electronic modules, Wi-Fi, MQTT, and IoT dashboards**.

This repository contains hands-on projects for learning embedded systems, sensor monitoring, device connectivity, and automation. Each project provides a starting point for exploring how microcontrollers and sensors can be used to build connected applications.

Whether you are an engineering student, beginner, educator, maker, or developer, these projects can help you explore IoT concepts through practical hardware and software examples.

## Project Collections

### ESP8266 IoT Projects

Explore ESP8266 NodeMCU projects using sensors and electronic modules for real-time monitoring and IoT applications.

Topics include:

- Light intensity and environmental monitoring
- Temperature and humidity measurement
- Motion, infrared, flame, gas, and sound detection
- Soil moisture and water level monitoring
- Distance and rain detection
- Motion sensing using MPU6050
- Voltage, current, and vibration monitoring
- Magnetic and capacitive touch sensing
- Atmospheric pressure and temperature measurement

**[Browse ESP8266 IoT Projects →](./esp8266/)**

Visit the [ESP8266 project index](./esp8266/README.md) to explore the available projects, documentation, circuit connections, source code, and testing instructions.

### Arduino and KiwisIoT Setup

New to KiwisIoT with ESP8266? Start with the [KiwisIoT Arduino Setup Guide](./esp8266/kiwisiot-arduino-setup/) to prepare the Arduino IDE and configure the KiwisIoT library.

## Technologies and Tools

- **IoT platform:** [KiwisIoT](https://kiwisiot.in/)
- **Microcontrollers:** ESP8266, ESP32, and Arduino-compatible boards
- **Development environment:** Arduino IDE
- **Connectivity:** Wi-Fi and MQTT, where supported by the project
- **Hardware:** Sensors, electronic modules, and input/output devices
- **Applications:** Sensor monitoring, dashboards, automation, and connected devices

## What You Can Learn

By exploring these projects, you can gain practical experience with:

- Interfacing sensors and electronic modules with microcontrollers.
- Reading analog and digital sensor data.
- Programming ESP8266 and other compatible boards using the Arduino IDE.
- Working with sensor libraries and communication interfaces.
- Sending sensor readings and device status to an IoT platform.
- Visualizing data using dashboard widgets.
- Testing, troubleshooting, and extending embedded systems projects.

## Who Can Use These Projects?

This repository is suitable for:

- Engineering students learning IoT and embedded systems.
- Beginners exploring Arduino and ESP8266 development.
- Educators preparing practical electronics demonstrations.
- Makers experimenting with sensors and connected devices.
- Developers prototyping sensor-monitoring applications.

Each project may have different hardware requirements, libraries, and configuration steps. Refer to the individual project documentation before assembling and testing a circuit.

## About KiwisIoT

[KiwisIoT](https://kiwisiot.in/) is an IoT platform for connecting devices, sending data, and visualizing information through dashboards.

These projects demonstrate practical ways to integrate microcontrollers and sensors with KiwisIoT for learning, prototyping, monitoring, and connected-device applications.

Visit the [KiwisIoT website](https://kiwisiot.in/) to learn more about the platform.
